# Sales Analytics Dashboard

**Portfolio project | Python • Pandas • PostgreSQL • SQL • Power BI**

An end-to-end retail sales analytics project designed to transform raw order-level data into business insights and an interactive Power BI report.

## Business questions

1. What are total sales, profit, order count, customer count, and profit margin?
2. How do sales and profit change over time?
3. Which categories and sub-categories contribute most to sales and profit?
4. Which regions and states are most/least profitable?
5. How do discounts relate to profitability?
6. Which customers and products contribute most to revenue?
7. How does shipping duration vary by ship mode?

## Dataset

This project expects the **Sample Superstore** CSV, commonly used for retail analytics practice.

1. Download a copy from a source whose terms permit educational/portfolio use.
2. Save it as `SampleSuperstore.csv`.
3. Place it in `data/raw/SampleSuperstore.csv`.
4. Preserve the raw file unchanged. The Python script writes cleaned output separately.

Expected fields include Order ID, Order Date, Ship Date, Customer ID, Customer Name, Segment, Region, Category, Sub-Category, Product Name, Sales, Quantity, Discount, and Profit. The scripts normalize column names to lowercase snake_case.

## Run the Python pipeline

From the repository root:

```powershell
py notebooks/01_data_cleaning.py
py notebooks/02_exploratory_data_analysis.py
py src/validate_project.py
```

Generated outputs:
- `data/processed/sales_cleaned.csv`
- `data/processed/data_quality_report.json`
- `reports/figures/*.png`
- `reports/eda_summary.txt`

These outputs are generated locally and excluded from Git by default. Review the quality report and charts before writing business conclusions.

## PostgreSQL

1. Create a database, e.g. `sales_analytics`.
2. Connect to it and execute `sql/01_create_tables.sql`.
3. Import `data/processed/sales_cleaned.csv` into `sales_cleaned` using pgAdmin's Import/Export tool (CSV, Header = Yes), or use the `\copy` example in the SQL file.
4. Execute `sql/02_business_analysis.sql`.

Check that the imported column mapping matches the table definition. If the source CSV has extra columns, either add those columns to the table or import only the matching columns.

## Power BI

1. Run the Python cleaning script.
2. In Power BI Desktop choose **Get data → Text/CSV** and select `data/processed/sales_cleaned.csv`.
3. Rename the imported table to `sales_cleaned`.
4. Confirm date and numeric data types.
5. Add measures from `powerbi/DAX_Measures.md`.
6. Follow `powerbi/Dashboard_Build_Guide.md`.
7. Save the report as `powerbi/Sales_Analytics_Dashboard.pbix`.

The `.pbix` is a Power BI Desktop artifact and must be created and saved in Power BI Desktop; it is not generated by these source-code files.

## Metric definitions

- **Total Sales:** sum of line-level sales.
- **Total Profit:** sum of line-level profit.
- **Profit Margin:** total profit divided by total sales.
- **Total Orders:** distinct count of Order ID.
- **Average Order Value:** total sales divided by distinct orders.

Do not average row-level profit margins to calculate an overall margin. Use `SUM(profit) / SUM(sales)`.
